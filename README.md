## The entry

One word describing my Wi-Fi: **Ghosting**.

It vanishes mid-sentence, mid-call, mid-download — no warning, no goodbye — then comes back a minute later pretending nothing happened. Everyone has been ghosted by their router at least once.

## How it works

`main.ts` writes that single word to `/output/entry.txt`:

```sh
node main.ts
```

No dependencies, no network, no flags — just plain Node.
